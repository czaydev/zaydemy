## 2024-10-24 - O(n²) Array Filtering Anti-Pattern in Server Components
**Learning:** Found a common codebase-specific performance bottleneck where related entities fetched via separate DB queries (due to complex filtering/aggregation limits in single queries) are joined manually in Server Components using `O(n²)` array methods (like `.find` or `.filter` in a `.map` loop). Examples found in `apps/web/src/app/admin/courses/page.tsx`, `apps/web/src/app/admin/users/page.tsx`, and `apps/web/src/app/page.tsx`.
**Action:** When manually resolving relationships in Server Components, always iterate the related items array exactly once to build a lookup `Map` (for 1:1 or aggregates) or a grouped `Map` (for 1:N), changing the subsequent `O(n²)` nested loop rendering into an `O(n)` map lookup.
