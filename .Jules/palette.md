## 2023-11-20 - [ARIA labels for Icon-heavy Menus]\n**Learning:** The user menu button in this application relies heavily on visual cues (Avatar and ChevronDown) where text is hidden on small screens (`hidden sm:block`). This creates an accessibility gap for mobile screen reader users who cannot infer the button action.\n**Action:** Add clear `aria-label` attributes to trigger buttons that rely heavily on responsive display text and icons, like `aria-label="User menu"`.
